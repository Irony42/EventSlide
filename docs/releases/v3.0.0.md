## GitHub release: body

> **EventSlide is now licensed under AGPL-3.0-only.** `v2.1.0` is the first release under it.
>
> **If you run EventSlide without modifying it, nothing new is asked of you.** No notice, no
> registration, nothing to publish. Your guests and hosts will see a small "Source code
> (AGPL-3.0)" link in the footer of the guest and host screens, in their language. It points
> at the source of the version you run, and it cannot be switched off.
>
> **If you modify it and let other people use your version over a network**, the AGPL
> (section 13) asks you to offer them the source of your version. Publish it, and set
> `SOURCE_CODE_URL` to where it is.
>
> **Nothing published before is relicensed.** Every commit up to and including
> `5c2607380ebb18045a14cae979bb54e6fa2def76`, the tag `gpl-final`, stays available under
> GPL-3.0 for good.
>
> Questions, case by case (unmodified, modified, forked):
> [docs/LICENSING-FAQ.md](https://github.com/Irony42/EventSlide/blob/v2.1.0/docs/LICENSING-FAQ.md).
>
> Before you upgrade, read "Behaviour changes to check before upgrading" in the
> [CHANGELOG](https://github.com/Irony42/EventSlide/blob/v2.1.0/CHANGELOG.md). In particular,
> `compose.yaml` now reads your `.env`.

## GitHub Discussion

Category: Announcements (pinned). Title: **EventSlide is now AGPL-3.0-only: what changes for
you**

> `v2.1.0` changes EventSlide's licence from GPL-3.0 to **AGPL-3.0-only**. This post says what
> that means if you run it yourself.
>
> **Why.** The GPL asks you to share the source when you hand a copy of a modified program to
> someone. It says nothing about running a modified copy on a server for other people, because
> then nobody receives a copy: someone could change EventSlide, run it for the public and never
> publish a line. The AGPL closes that gap with one extra clause, section 13. It does not take
> anything away from the people who run EventSlide as it is.
>
> **If you build and run a tagged release without modifying it:** nothing new is asked of you.
> You owe nothing. Your guests and hosts will see a small "Source code (AGPL-3.0)" link in the
> footer of the guest and host screens, in their language. It points at the source of the
> version you run, and it cannot be switched off.
>
> **If you modify it and other people use your version over a network** (your event guests
> count): offer them your source. Publish it, and set `SOURCE_CODE_URL` to that page. The link
> in the footer and `GET /api/about` then offer your version instead of ours.
>
> **If you fork it:** your fork is AGPL-3.0-only too. Point `SOURCE_CODE_URL` at it.
>
> **Older versions.** Nothing published before the change is relicensed. The last GPL commit is
> `5c2607380ebb18045a14cae979bb54e6fa2def76`, recorded in `.github/gpl-boundary`, and the tag
> `gpl-final` is cut on it. To know which licence a build is under, read the `LICENSE` file at
> its commit.
>
> **Nothing is removed.** The licence change takes no feature out of EventSlide and puts none
> behind anything.
>
> The [licensing FAQ](https://github.com/Irony42/EventSlide/blob/v2.1.0/docs/LICENSING-FAQ.md)
> covers each case. This is not legal advice. If your situation is not in it, ask here.
