## GitHub release: body

> **EventSlide 3.9 has its brand logo, a fix for a Dependabot alert and a CI that no longer lets flaky tests hide.**
>
> - **The new logo.** A "tirage suspendu" icon for the browser tab, the install and the iOS home screen; the
>   lockup on the sign-in pages, the events list, About, the error page and the 404, with a garland on the
>   sign-in; the mark in the host console header, linking to the events list. The guest pages and the wall are
>   unchanged.
> - **`minimatch` 11.0.1** for Dependabot alert #44. Not reachable from untrusted input: nothing in the product
>   passes a pattern to the library.
> - **Patch bumps** of `express-rate-limit`, `nodemailer` and `react-router-dom`, the development tools, and the
>   Node base image digest.
> - **Flaky tests fixed, and a guard**: a test that passes only on a retry now fails the CI job.
>
> **This is a minor release and breaks nothing.** No migration (the last is still 026), no new environment
> variable, nothing to change before upgrading: pull the image and restart. See the
> [CHANGELOG](https://github.com/Irony42/EventSlide/blob/v3.9.0/CHANGELOG.md).
